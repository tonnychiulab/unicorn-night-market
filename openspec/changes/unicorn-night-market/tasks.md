# Tasks

## 1. 單檔骨架

- [x] 1.1 建立 `index.html`，內含 canvas、標題「獨角獸夜市」，以及系統繁中字型堆疊。用瀏覽器打開，確認不請求外部圖片、字型或音檔。
- [x] 1.2 接上空白鍵、Enter 與 pointerup，兩者都呼叫同一個端出函式，按住不重複觸發。在標題畫面按鍵與點擊都能進入做菜，以此驗證。

## 2. 攤位服務

- [x] 2.1 做循環掃描標記，並為豬血糕、臭豆腐、炸皮蛋各放一組區間表（太生／剛好／烤焦、太清淡／剛好／太臭、油溫不夠／剛好／皮蛋破了）。連續開三客不同品項，確認畫面品名與失敗文案對得上該組區間。
- [x] 2.2 每一客顯示倒數，歸零未端出則失敗原因為逾時。把倒數調短後等待，確認出現逾時且不加分。

## 3. 獨角獸與夜市

- [x] 3.1 用 Canvas 畫出夜晚攤販（暖色燈、油煙或蒸氣）與一隻獨角獸，文案為繁體中文。打開對局，確認看得到獨角獸與夜市，而不是空白或一般餐廳畫面。
- [x] 3.2 實作彩虹勇氣：成功 +15，太生或太清淡 −10，其餘失敗 −25，並在重口失敗時畫出彩虹噴出或退開。各觸發一次，確認勇氣升降與表現符合上述。
- [x] 3.3 第一次按鍵或點擊才建立 WebAudio，成功與失敗各有短音。靜音環境外，確認開局不會自動出聲，端出後聽得到回饋。

## 4. 一局流程

- [x] 4.1 串起 title、cook、beat、over。勇氣大於 0 就派下一客；降到 0 顯示最終分數與再來一局。故意連續失敗到收攤，確認分數只在成功時增加，再來一局後分數為 0、勇氣回到滿值。

## 5. 整合與體積

- [x] 5.1 用鍵盤走完一局、用點擊或觸控再走完一局，三種小吃的成功與失敗都至少出現一次。對照三份 spec 的場景，缺的補上。
- [x] 5.2 將 `index.html` 壓成 zip，確認大小 ≤ 13,312 bytes。超過就先砍粒子與音效層數，保留判定、勇氣、分數與再來一局，再壓一次直到通過。
